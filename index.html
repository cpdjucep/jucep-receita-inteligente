Fonte e metodologia

Fonte primária: API de Receita Orçamentária dos Dados Abertos da CODATA/PB. O painel consulta exclusivamente registros cujo órgão é “JUNTA COMERCIAL DO ESTADO DA PARAIBA”. Os valores exibidos refletem o retorno da fonte na data e hora da consulta e podem ser revisados pelo órgão responsável.

O acumulado anual soma os meses efetivamente consultados; em caso de falha em qualquer mês, o acumulado não é apresentado como completo. Receita prevista igual a zero significa que a API retornou zero para os registros consultados, não necessariamente ausência de previsão no orçamento anual.
